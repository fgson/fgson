## About

Most of my projects start with a real problem that needs solving — an admin task
worth automating, an integration that should be less fragile, or a small tool
that makes everyday work easier.

I enjoy working close to the system: software, Linux, networking, self-hosting
and containers. I also have a soft spot for retro computing and hardware
projects.
